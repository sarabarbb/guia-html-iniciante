# guia-html-iniciante
Guia básico para iniciantes sobre fundamentos do HTML, tags essenciais e dicas de outros conteúdos para aprofundamento..

Dia 13/08: Meu Diário de Bordo: Big Bang Blog 💥
"Nesta primeira etapa do meu aprendizado no desenvolvimento Front-end, construí a estrutura base do Big Bang Blog do zero! 🚀

Aqui está um resumo do que eu já coloquei em prática no meu código:

🏗️ Estrutura Fundamental: Organizeio o documento HTML completo com as tags &lt!DOCTYPE html&gt, &lt;html&gt;, &lt;head&gt; (configurando idioma e responsividade) e &lt;body&gt;.

⚓ Navegação Prática: Criei um índice navegável no topo da página. Usei os atributos id="o-big" e id="o-bang" nos subtítulos &lt;h3&gt; para funcionarem como alvos, e os conectei com links &lt;a&gt; através do href.

🎨 Estilização e Organização: Experimentei usar classes como titulos-cor-padrao e apliquei estilos diretamente com o atributo style para personalizar fontes, cores e remover as bolinhas da lista explicativa (list-style-type: none).

🖼️ Mídia Semântica: Inseri a imagem sobre a estrutura do HTML utilizando as tags &lt;figure&gt; e &ltfigcaption&gt para garantir a acessibilidade e registrar os créditos da fonte de forma correta.

🔤 Caracteres Especiais: Utilizei as entidades &lt; e &gt; para conseguir exibir os nomes das tags (como &lt;h1&gt;, &lt;head&gt; e &lt;body&gt;) como texto na tela sem que o navegador as interpretasse como código."

Eu tive algumas dificuldades — na verdade, tenho muitas ideias para esse código, mas estou tentando me ater ao que foi pedido na aula, que já é bastante coisa para quem está começando.

Apesar disso, eu ainda lembrava de algumas coisas das outras vezes em que estudei HTML, então decidi tentar aplicar algumas delas por conta própria. E, para minha surpresa, deu super certo!

Também consultei a W3Schools para entender a forma correta de utilizar algumas tags, e foi bem fácil compreender.

Ainda faltam algumas tags que foram solicitadas para este projeto, então vou me empenhar para terminar tudo amanhã. Até aqui, está sendo bem interessante perceber que algumas coisas que pareciam difíceis começam a fazer sentido quando coloco a mão no código.
